## 最近验证命令与结果

```sh
cargo fmt --check
cargo clippy --locked --all-targets -j 2 -- -D warnings
JXPAN_LIVE_ORACLE=1 cargo test --locked -j 2
python3 tools/verify-pages.py
python3 tools/verify-live.py --baseline <明确授权的现有服务地址>
```

- 全套 Rust 测试最近一次：75 项通过；测试项不等于 75 个不同业务功能。已去掉重复的存储模块编译与重复 fixture。
- 差分 fixture 是合成输入经过冻结原部署计算得到，不包含实际账号或实际分享。
- 移动：目录 JSON 完全相等；两端均 302；CDN GET Range 均 206；只读取 1 字节；HEAD 两端均 403。这是样本验证，不代表所有分享场景完成。
- `verify-live.py` 当前整体退出非零：移动通过，天翼成功下载断言未通过。不得把它报告为整套 live 验证成功。
- 天翼：已找到已有 STRM 的只读样本，目录 JSON 相等；该样本的当前旧服务和 Rust 下载均失败（502），因此**未通过成功下载闭环**。
- 天翼 fast 失败的 HTTP 状态已修正，不再错误地用 HTTP 200 包装 502。
- 若单文件响应包含时变签名 URL，只在明确的 `data.download_url` / `data.files[*].url` 路径做比较规范化；下载行为仍须独立实测，不能仅忽略 URL 就判定通过。

## 已知不完全兼容处（不能隐瞒）

- 后台、扫码/续期路由、统计/历史/短链等还未全部实现；调用返回 501。
- 天翼只读单文件下载无法取得直链时，不执行旧版转存/删除回退；该功能尚未完成。
- 原协议中不安全的 URL/跨主机凭据转发会被拒绝。此类安全差异需单独记录，而不是称为逐字复刻。
- 当前凭据从配置文件/环境变量在启动时读取，后台动态切换尚未接通。
- 缓存键使用每进程随机 HMAC，覆盖凭据作用域、密码、URL、目录链、文件 ID、sid、下载方式；失效后重试还须与真实续期流程联测。
